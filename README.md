# 太玄界 · 修仙大世界

当前正式版本：**V2.9.0 · 前尘旧缘（build 2901）**

## 开发唯一任务基准

后续开发统一按 [`docs/PROJECT_TASKBOOK.md`](docs/PROJECT_TASKBOOK.md) 执行。

长期主线已经确定为：

**凡人 → 炼气 → 筑基 → 结丹 / 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 飞升 → 真仙。**

其中 V3 系列先完成玩家成长体系、炼虚/合体/大乘、渡劫与真仙终局，并完成“无充值从凡人到真仙”的总平衡；只有全部通过后，才进入 V4.0 深度模拟充值 / VIP / 商城，再进入 V4.1 模拟运营。

正式运行结构：`index.html -> app.js -> src/game-v29.js`。浏览器直接加载可读源码，不使用历史补丁链或 `eval`。

## V2.9
- 完整保留 V2.8 的 NPC 求援、人情债、仇怨伤亡、动态势力归属和重大人生事件；
- 本世结束时，关系达到 60 的深交 NPC 会被写入历世旧缘，不记录普通泛泛之交；
- 轮回仍然保留世界、NPC 年龄、境界、势力与命运，但玩家与 NPC 的直接关系继续归零；
- 修复上一世 `favorDebt` 和 `npcPendingRequest` 错误跨世继承：转世时旧人情债与未处理求援会被明确结清；
- 新一世与旧日深交第一次真正重逢时，只获得 +4～6 的小额关系，不直接继承上一世高好感；
- 极深旧缘重逢可触发一次很小的资源或悟道机缘，同一人生不能重复领取；
- 人物关系页新增“前尘旧缘”，可查看历世深交、旧人当前生死/位置以及本世是否已经重逢。
