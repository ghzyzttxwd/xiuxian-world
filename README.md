## V2.6
- 完整保留 V2.5 的外门→内门→真传→执事→长老宗门生涯、师承、晋升考核与高阶差事；
- 四位青云宗长老拥有独立年龄、境界、修炼进度、闭关状态、突破记录与寿元，会随世界时间真正变化；
- 师父闭关期间无法请教；师父寿尽坐化后原师承失效，可改投仍在世的长老，但师徒情分折半；
- 新增六名持久化主要同门，他们会自行修炼、积累功绩、突破并在外门/内门/真传/执事/长老之间晋升，也会寿尽；
- 内门以后自动形成长期竞争对手；青云论剑使用真实战斗系统，但属于非致命切磋，不计击杀、不掉高阶灵材、失败不死亡也不掉灵石；
- 宗门内部事件按时间轮转：青云论剑小比、秘库配额评议、诸峰讲法会；参与结果会改变宗门资历、贡献、资源、师徒情分与同门竞争关系。
