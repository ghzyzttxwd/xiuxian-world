# 太玄界 · 修仙大世界

当前正式版本：**V2.1.0 · 四大道途与流派分化（build 2101）**

正式运行结构：`index.html -> app.js -> src/game-v21.js`。浏览器直接加载可读源码，不使用历史补丁链或 `eval`。

## V2.1
- 保留凡人至化神后期 26 境界、12 地域、20 路线以及 V2.0 高阶丹药/法宝循环；
- 结丹境起可正式选择四条主修道途：青云剑道、赤霞火道、万兽炼体、太虚神道；
- 四条道途拥有真实属性取舍：剑修重近战与御剑爆发，火法法术最高但更脆，体修气血/减伤最强但法术削弱，神识流灵力与控制最强但肉身较弱；
- 每条道途拥有专属功法与绝学：御剑连斩、焚脉真火、崩山式、摄魂印；
- 专属绝学直接进入实际战斗循环，包括连斩、持续灼烧、炼体护架、神魂封压；
- 道途熟练度由专属绝学和实战增长，并直接提高招牌绝学倍率；
- 主修允许转修，但额外消耗悟道、折损一半道途熟练度；旧技能保留，不删除旧档内容；
- 在与当前道途匹配的秘境通关会触发道途共鸣，额外提高熟练度；
- 青云剑道与宗门贡献挂钩，其他三道分别绑定赤霞谷、万兽山脉、古河遗迹/玄阴禁地，使地图与传承来源产生实际区别。
