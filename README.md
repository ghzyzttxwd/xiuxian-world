# 太玄界 · 修仙大世界

当前正式版本：**V2.3.0 · 三方势力与长期立场（build 2301）**

正式运行结构：`index.html -> app.js -> src/game-v23.js`。浏览器直接加载可读源码，不使用历史补丁链或 `eval`。

## V2.3
- 保留凡人至化神后期 26 境界、12 地域、20 路线、V2.0 高阶生态、V2.1 四大道途和 V2.2 道途世界反馈；
- 新增青云宗、玄水帮、血刀门三方持久化势力关系，范围 -100 到 100，并划分死敌、敌视、中立、友善、盟友；
- 三方均提供可重复势力委托且有 10 日冷却：青云宗清剿黑风妖患、玄水帮镇压云梦水患、血刀门赤岭试刀；
- 委托不是点击即领奖，必须在指定地域完成真实战斗胜利并累计进度；
- 完成委托提高对应势力关系；青云宗与血刀门互为主要敌手，帮助一方会真实损伤另一方关系；
- 青云宗弟子维持最低青云宗认可，并禁止公开承接血刀门委托；
- 势力关系直接进入青云/玄水/血刀路线风险计算：友善降低风险，敌视提高风险；
- 玄水帮关系直接进入临江坊市灵草、回春散买价：友善折扣，死敌加价；
- 被某势力视作死敌后，该势力 NPC 会拒绝正常赠礼、论道、切磋与求助；
- 青云宗与血刀门大战的每次真实胜利都会写入双方长期关系，而不再只影响一次性战场贡献。
