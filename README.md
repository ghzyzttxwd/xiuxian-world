# 太玄界 · 修仙大世界

当前正式版本：**V1.5.0 · 十二地域与区域生态（build 1501）**

## 正式运行结构

```text
index.html
  -> app.js
  -> src/game-v15.js
```

浏览器继续使用直接可读源码，不恢复历史运行时补丁链或 `eval`。

## V1.5 世界扩张

地图由原来的 5 个地点扩展为 12 个连通地域：青石村、青石镇、临江城、黑风岭、青云山、云梦泽、苍梧郡城、赤霞谷、落星矿脉、万兽山脉、古河遗迹、玄阴禁地。

区域差异已经进入真实玩法：

- 探索遇敌概率按地区危险度变化；
- 采集收益按地域灵草资源变化；
- 谋生收入按当地经济与资源变化；
- 新区域拥有专属敌人；
- NPC 初始活动范围受所属势力影响，并沿道路网络移动；
- 地域事件按本地特产结算不同收益；
- 动态秘境扩展到新区域，并按地域秘境活跃度加权；
- 高危险区域生成的秘境基础威胁更高；
- 地图页直接显示危险、势力、特产、秘境活跃度。

## 存档兼容

## 工程与发布

- `main`：唯一开发源。
- `gh-pages`：公开部署产物。
- `tools/build-v15-world.cjs`：从已验证的 V1.4 直读源码生成 V1.5 世界扩张源码。
- `tests/regression-v15.mjs`：V1.5 地图/生态与既有系统回归。
- `.github/workflows/v15-world.yml`：PR 只验证；main trigger 才构建、发布、公网重新下载、运行回归并写 PASS。
- V6 App 图标继续做 SHA-256 回归，不修改。
