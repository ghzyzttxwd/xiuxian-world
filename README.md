# 太玄界 · 修仙大世界

当前正式版本：**V2.2.0 · 道途世界反馈（build 2201）**

正式运行结构：`index.html -> app.js -> src/game-v22.js`。浏览器直接加载可读源码，不使用历史补丁链或 `eval`。

## V2.2
- 保留凡人至化神后期 26 境界、12 地域、20 路线、V2.0 高阶生态与 V2.1 四大道途战斗差异；
- 四条道途获得世界共鸣地域：剑道（青云山/落星矿脉）、火道（赤霞谷/黑风岭）、炼体（万兽山脉/黑风岭）、神识（古河遗迹/玄阴禁地）；
- 共鸣地域的地域事件有 55% 概率转为当前道途专属机缘；每条道途都有稳妥/激进两种真实结算选择；
- 新增持久化的分道途名望 `daoRenown` 与累计道途机缘 `daoEncounters`，转修不会抹掉旧道途名望；
- NPC 新增稳定 `daoAffinity` 道途倾向；同道论道会额外提升关系、道途熟练度和名望；同道切磋也会强化这些反馈；
- 人物关系列表直接显示 NPC 道途倾向以及是否“与你同道”；
- 地图会对当前主修路线的共鸣地域标记“道途共鸣”；
- 青云宗月俸会识别青云剑道名望，并按名望追加宗门贡献；
- V2.1 的四种招牌绝学、转修惩罚、秘境共鸣、属性取舍、全部旧系统继续保留。

## 存档
