# 太玄界 · 修仙大世界

低美术、高事件、高数值、持续世界演化的修仙沙盒 RPG。

## 当前版本：V0.1 核心循环

已实现：

- 创建角色
- 360 天制时间推进、季节、年龄、寿元
- 凡人 → 炼气九层 → 筑基后期的初版境界链
- 修炼、采药、谋生、打听、休整、探索
- 5 个地点与赶路耗时
- 16 个会自行修炼、突破、移动、死亡的 NPC
- 世界兽患、势力、物价等动态数值
- 5 类可选择的随机事件
- 固定历史事件 + 条件触发事件
- 大事件预告、开启、限时参与、错过后世界自动结算
- 青云宗收徒、黑风岭兽潮、苍梧古洞三条大事件
- 玩家参与会改变奖励、声望和部分世界状态
- localStorage 自动存档
- 手动存档、导出 JSON 存档、重开
- 手机/电脑响应式界面

## 运行

当前版本是一个完全自包含的 `index.html`，不依赖 npm、后端、数据库或外部素材。

下载 `index.html` 后可直接用现代浏览器打开。后续若启用 GitHub Pages，也可直接作为网页运行。

## 当前开发原则

1. 先让世界和玩法成立，再加图片。
2. 图片只增强氛围，不承担主要游戏内容。
3. 每次玩家行动都会消耗世界时间，NPC 与世界同步演化。
4. 大事件有时间窗口，玩家可以参加，也可以错过；世界不会等待玩家。
5. 后续核心引擎应尽量可复用于武侠大世界项目。
