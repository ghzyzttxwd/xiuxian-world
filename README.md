# 太玄界 · 修仙大世界

当前正式版本：**V1.6.0 · 行旅路线与途中风险（build 1601）**

## 正式运行结构

```text
index.html
  -> app.js
  -> src/game-v16.js
```

浏览器继续直接加载可读源码，不恢复历史补丁运行时或 `eval`。

## V1.6 行旅系统

V1.5 的 12 地域完整保留。V1.6 把“赶路只扣天数”升级为真实路线选择：

- 全图建立 20 条具体行旅路线；
- 临江城→云梦泽、临江城→苍梧郡城存在不同路线选择；
- 不同路线有独立天数、基础风险、路线类型、控制势力和路费；
- 青云宗弟子走青云控制路线风险降低，进入血刀门活动路线风险上升；
- 重伤与宗门冲突紧张度会提高特定路线风险；
- 付费护送/商船路线用灵石换更低风险或更短时间；
- 途中可能遭遇真实战斗；
- 也可能触发水路采药、荒野兽材、遗迹感悟、商旅酬谢、沿途传闻等见闻；
- 地图按钮直接展示路线名、耗时、风险和路费。

## 存档兼容
