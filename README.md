# 太玄界 · 修仙大世界

当前正式版本：**V2.0.0 · 高阶修炼生态（build 2001）**

正式运行结构：`index.html -> app.js -> src/game-v20.js`。浏览器直接加载可读源码，不使用历史补丁链或 `eval`。

## V2.0
- 暂停机械追加境界，保留凡人至化神后期 26 境界长线；
- 新增【高阶灵材】，金丹以上敌人与高境界秘境会进入真实产出循环；
- 新增金元丹、养魂丹：炼制有真实材料、时间、成功率与失败损耗，服用后产生实际修为/灵力/伤势/悟道效果；
- 法器从三件低阶装备扩展到赤霄丹剑、玄龟灵甲、元神玉佩、太虚神剑；
- 高阶法宝需要兽材、高阶灵材以及结丹灵髓/化婴灵胎/化神道种等对应资源；
- 法宝法术增幅真实进入火弹术、金焰剑诀、神念斩伤害公式；
- 秘境核心在金丹以上会额外产出高阶灵材，使探索、战斗、炼丹、炼器形成闭环；
- V1.9 的 26 境界、12 地域、20 路线、宗门、洞府、NPC、秘境、轮回、宗门大战、结丹/化婴/化神体系全部保留。
