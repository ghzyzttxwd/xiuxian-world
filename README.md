# 太玄界 · 修仙大世界

当前正式版本：**V1.7.0 · 结丹与金丹长线（build 1701）**

## 正式运行结构

```text
index.html
  -> app.js
  -> src/game-v17.js
```

浏览器继续直接加载可读源码，不恢复历史补丁运行时或 `eval`。

## V1.7 境界长线

在 V1.6 的十二地域与 20 条行旅路线基础上，境界从筑基后期继续扩展：

- 筑基圆满
- 结丹境
- 金丹初期
- 金丹中期
- 金丹后期

普通小境界继续使用原有主动突破。筑基圆满→结丹、结丹→金丹改为独立的大境界规则：

- 结丹需要 3 份结丹灵髓、2 点悟道，闭关 12 日；
- 凝结金丹需要 2 份结丹灵髓、3 点悟道，闭关 9 日；
- 必须无伤才能尝试；
- 材料在开始冲关时真实消耗；
- 失败会回退修为、加重伤势、损失寿元并积累破境感悟；
- 结丹成功将寿元下限提升到 300，金丹成功提升到 500；
- 旧筑基存档迁移后寿元下限补到 150。

## 结丹资源与高境界世界

- 筑基后期可在赤霞谷、落星矿脉、古河遗迹淬炼结丹灵髓；
- 每份灵髓消耗灵草 4、兽材 2、灵石 6，推进 2 日；
- 深层地区新增筑基、结丹、金丹级敌人，其中部分会掉落结丹灵髓；
- NPC 不再被锁死在炼气八层，可继续沿完整境界表成长；
- 战斗加入境界压制，跨多个小境界时攻防差距会真实进入伤害公式。

## 存档兼容

V1.7 增加持久化字段 `coreEssence` 与 `coreFailures`，因此 `saveSchemaVersion` 从 13 升至 14。旧 schema 2→13 迁移链完整保留，并新增 13→14 迁移；schema 15+ 的未来存档仍拒绝加载且绝不覆盖。

## 工程与发布

- `main`：唯一开发源。
- `gh-pages`：公开部署产物。
- `tools/build-v17-core-realm.cjs`：由 V1.6 正式源码生成 V1.7 境界长线源码。
- `tests/regression-v17.mjs`：境界链、大境界材料门槛、成功/失败寿元、境界压制、V1.6 存档迁移及既有系统回归。
- `.github/workflows/v17-core-realm.yml`：PR 只验证；main trigger 才发布并进行公网重新下载、源码哈希和 headless 回归。
- V6 App 图标继续做 SHA-256 回归，不修改。
