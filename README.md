# 太玄界 · 修仙大世界

当前正式版本：**V2.8.0 · NPC人生后果（build 2801）**

正式运行结构：`index.html -> app.js -> src/game-v28.js`。浏览器直接加载可读源码，不使用历史补丁链或 `eval`。

## V2.8
- 完整保留 V2.7 的动态年龄、伤势、历练、秘境、势力战、NPC关系网络、真实助阵和故人录；
- 关系较好的 NPC 在真实困境中会主动向玩家求援，援手会消耗回春散、灵草或灵石，拒绝和失约也有关系后果；
- 帮助 NPC 会形成持久化 `favorDebt`，旧恩可在数十日后转化成真实资源回报，并提高故人战斗助阵意愿；
- NPC↔NPC 深仇会低频升级为冲突、负伤，极深仇怨可能真正决出生死，死亡继续进入 V2.7 故人录；
- 散修可加入青云宗、玄水帮或血刀门，部分受创成员会退出为散修；青云宗/血刀门人口变化会轻微影响势力强度；
- 新增低频重大人生事件：机缘、洞府、功法、失财、重伤隐退、寿元压力下的闭死关，事件都会修改真实人物状态；
- 重伤隐退和闭关期间，NPC 不再照常移动、闯秘境或参加势力战；
- 人物关系页新增“人生后果”面板，可处理当前求援并查看人情、仇怨死亡、势力变化和人生事件统计。
