# 太玄界 · 修仙大世界

当前正式版本：**V2.5.0 · 青云宗门生涯（build 2501）**

正式运行结构：`index.html -> app.js -> src/game-v25.js`。浏览器直接加载可读源码，不使用历史补丁链或 `eval`。

## V2.5
- 保留 V2.4 的 26 境界长修炼曲线、强大境界压制、寿元终结与全部既有地图/道途/势力系统；
- 青云宗身份扩展为外门弟子、内门弟子、真传弟子、宗门执事、宗门长老五级；
- 每次晋升同时要求境界、任务、贡献、师承、青云关系和真实宗门战斗考核，不能只点按钮升职；
- 晋升考核使用真实战斗，但属于非致命宗门试炼：失败不死亡、不掉灵石，通过后同级不能反复刷奖励；
- 内门后可在四位长老中择师，30日一次正式请教；师徒情分进入真传、执事、长老晋升条件，同道师承额外增长道途熟练；
- 真传解锁古河遗迹镇禁，执事解锁玄阴禁地巡狩，均要求真实战斗完成；
- 月俸与贡献兑换随身份升级，高阶弟子和长老可获得高阶灵材、悟道名额等宗门资源配额。
