# 太玄界 · 修仙大世界

当前正式版本：**V2.7.0 · NPC命运网络（build 2701）**

正式运行结构：`index.html -> app.js -> src/game-v27.js`。浏览器直接加载可读源码，不使用历史补丁链或 `eval`。

## V2.7
- 完整保留 V2.6 的宗门人物生态、V2.5 五级宗门生涯和 V2.4 凡修生存/寿元体系；
- 普通 NPC 获得动态年龄、伤势、历练次数、秘境次数、势力战次数、死亡原因与死亡日期；
- NPC 使用真实境界寿元上限，寿元耗尽会坐化，危险历练、秘境和青云—血刀冲突也可能造成受伤或死亡；
- 新增持久化 NPC↔NPC 关系网络，同地相遇会逐步形成交情或仇怨；
- 已知故人死亡进入永久故人录；与玩家交情深厚者死亡会留下个人经历与好友陨落统计；
- 与玩家关系足够好、同地且状态允许的 NPC，玩家遭遇真实战斗时可能加入助阵并直接扣减敌方气血；
- 人物关系页新增“人物命运”面板，可查看已知人物轨迹、NPC之间的关系和故人记录。

## 存档
V2.7 使用 `saveSchemaVersion = 24`，新增普通 NPC 生命周期、人际网络、历练/秘境/势力战经历和故人录。V2.6 schema23 自动迁移；未来 schema25+ 拒绝覆盖。
