# 太玄界 · 修仙大世界

当前正式版本：**V2.4.0 · 凡修生存重平衡（build 2401）**

正式运行结构：`index.html -> app.js -> src/game-v24.js`。浏览器直接加载可读源码，不使用历史补丁链或 `eval`。

## V2.4
- 保留凡人至化神后期 26 境界、12 地域、20 路线，以及 V2.0–V2.3 的高阶生态、四大道途、世界反馈、三方势力关系与真实委托；
- 完整移除原有额外修炼倍率和勤勉满 20 自动送悟道点两层外挂；修行历练仅作为实际行动记录；
- 重做 26 境界修为需求：前期仍可推进，筑基后明显变慢，金丹进入几十年级，元婴/化神逐步进入百年级长期成长；
- schema20 旧档迁移时按原境界完成百分比等比例映射到新需求，避免直接清零或凭空倒退；
- 大境界压制按凡人/炼气/筑基/金丹系/元婴/化神六个层级计算：跨一大境已经是显著压制，跨两到三大境接近不可正面对抗；
- 高境压低境同时提高战斗伤害，低境逆伐高境会显著减伤，高境敌人造成的战败死亡风险也同步上升；
- 普通小境界突破率随境界提高而下降；结丹、金丹、化婴、化神原有大突破材料和失败惩罚继续保留；
- 洞府七日闭关改为按真实七日修炼收益结算，不再按当前境界需求百分比直接跳大量进度；
- NPC 修炼速度同步放慢，避免玩家进入百年长线后 NPC 在数年内集体冲到顶境；
- 寿元耗尽会立即写入死亡原因、年龄、境界和日期并锁死本世，刷新/继续存档都不能恢复行动；只能轮回开启下一世；
- 剩余寿元 ≤10 年时首页开始预警，≤3 年和最后 1 年会进一步升级警告。
