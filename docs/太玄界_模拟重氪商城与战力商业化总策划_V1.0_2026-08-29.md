# 《太玄界》模拟重氪商城与战力商业化总策划 V1.0

> 日期：2026-08-29  
> 项目：ghzyzttxwd/xiuxian-world  
> 当前正式玩法基线：Gameplay V3.9.0 / Build 3903 / Save Schema 36  
> 当前商城基线：final-ui-shop-v2  
> 性质：用户个人单机游戏，本机模拟充值，不接真实支付，不产生真实扣款。

---

## 0. 本策划的任务

本策划不是继续做数值平衡，也不是新增一堆与现有玩法割裂的“氪金系统”。

目标只有一个：

**把《太玄界》现有真实战力系统全部接入商城，让充值奖励从“给资源”升级为“给战力组件、给Build质变、给阶段性毕业体验”。**

核心原则：

1. 小额商品解决即时资源短缺。
2. 中额商品解决成长卡点与流派缺件。
3. 高额商品必须提供肉眼可感知的战力跃升。
4. VIP8 / VIP12 / VIP15 必须分别对应三次明显的“账号质变”。
5. 所有奖励必须真正进入现有战斗计算，禁止只在商城里显示虚假“战力+XXXX”。
6. 不直接删除修仙过程。可以买得很强，但不能把突破、渡劫、飞升全部变成一键跳过。
7. 3903 核心默认冻结。优先通过外围商城适配层调用现有接口完成发奖；只有确认缺乏必要接口时，才单独评估最小核心改动。
8. 保持 Save Schema 36 兼容。
9. 本项目只有一个目标玩家：用户本人。无需照顾零氪公平、平民生态、排行榜公平或商业运营平衡。

# 一、现有真实战力树

商城施工必须围绕现有战斗系统，而不是凭空造“战力”。

## 1. 境界 / 修为

作用：

- 决定基础 HP / Qi；
- 决定修炼阶段；
- 参与境界压制；
- 解锁更高阶功法、技能、装备、法宝、空间、法则、本源、渡劫体系。

可商品化内容：

- 当前境界修为补给；
- 修为冲刺资源；
- 当前境界修为圆满（限重大VIP节点/极少数高价礼包）；
- 突破材料；
- 突破失败后的补救资源。

禁止：

- 普通礼包直接无条件跨大境界；
- 普通充值直接飞升真仙。

---

## 2. 功法

现有特征：

- 功法有品质与不同效果；
- 有独立熟练度；
- 可以收藏并切换；
- 不同Build会要求不同功法。

可商品化内容：

- 当前道途适配的稀有功法传承；
- 当前Build缺失功法补全；
- 功法熟练度加速；
- 高境界功法自选匣。

原则：

**高价功法商品应该解决“换一套打法”的问题，而不是单纯提高修炼速度。**

---

## 3. 主动技能 / 神通 / 被动

现有特征：

- 最多 6 个主动技能位；
- 1 个被动位；
- 技能有伤害、控制、护盾、持续伤害、斩杀、回复、反击等功能；
- Build成型直接依赖技能组合。

可商品化内容：

- 稀有主动神通；
- 核心被动；
- Build缺失技能补全；
- 当前道途神通自选匣；
- 高境界战斗神通；
- 渡劫专属护持技能。

---

## 4. 道途

现有四大道途：

- 剑道：近战、爆发、斩杀、剑阵；
- 火道：法术爆发、灼烧；
- 炼体：气血、防御、反震、重击；
- 神道：神魂、控制、吸取、法域。

可商品化内容：

- 入道礼包；
- 道途专属功法/技能/法宝；
- 道途切换后的重塑礼包；
- 道途专精资源。

商城必须识别玩家当前 daoPath，避免给剑修推纯火修核心礼包。

---

## 5. Build流派

当前核心Build至少包括：

### 剑道
- 剑心绝杀流；
- 剑阵封锁流。

### 火道
- 真火蚀脉流；
- 炎阳爆燃流。

### 炼体
- 金刚反震流；
- 蛮血重击流。

### 神道
- 太虚封禁流；
- 紫霄夺魂流。

Build检查维度：

- 对应功法；
- 对应被动；
- 对应道途法宝；
- 对应主动技能组合。

商业化重点：

**Build缺一件时，是最适合推高转化礼包的时刻。**

商品例：

- 【剑心圆满·最后机缘】
- 【真火大成·焚天传承】
- 【金刚不灭·镇岳秘藏】
- 【太虚封神·万念归一】

触发逻辑：

- Build score = 2：推“入门补全包”；
- Build score = 3~4：推“核心缺件包”；
- Build score >=5：不再卖同一套补全包，改推强化/法宝祭炼/高阶替换。

原则：

**不要重复卖玩家已经拥有的核心组件。**

# 二、装备与法宝：商城最重要的战力商品

## 1. 基础装备位

现有：

- 武器；
- 护甲；
- 佩饰。

真实属性包括：

- atk；
- def；
- hp；
- qi；
- spell；
- 各类被动倍率。

可商品化：

- 当前境界极品武器匣；
- 当前境界极品护甲匣；
- 当前境界极品佩饰匣；
- 当前Build适配装备套装。

但基础装备不应承担最高价商品定位。

---

## 2. 真正法宝位

现有四个法宝位：

- 攻伐；
- 护身；
- 辅助；
- 本命。

这是商城高价商品的核心。

法宝能真实提供：

- 基础战斗属性；
- 道途增伤；
- 法宝主动伤害；
- 控制；
- 护盾；
- 回复；
- 回灵；
- 斩杀；
- 反击；
- 灼烧；
- 冷却优势；
- 渡劫护持；
- 领域/法则/本源相关效果。

---

## 3. 法宝养成层

现有养成：

- 品质：普通 / 精良 / 上品 / 极品；
- 祭炼：0~9层；
- 温养：0~100；
- 认主；
- 本命化；
- 法宝受损与修复。

真实乘区：

- 品质倍率；
- 祭炼倍率；
- 温养倍率；
- 本命额外倍率；
- 对应道途额外倍率。

因此，高价商城商品绝不能只发“裸法宝”。

商品档次建议：

### 普通礼包

发：
- 普通/精良法宝；
- 未认主；
- 0~1层祭炼。

### 中高价礼包

发：
- 上品法宝；
- 自动认主；
- 祭炼2~3层；
- 温养20~30。

### VIP重大节点

发：
- 极品法宝；
- 自动认主；
- 祭炼3~5层；
- 温养30~50；
- 必要时自动装入对应法宝位；
- 如果满足阶段条件，可直接本命化，或发“本命化资格/材料”。

# 三、高境界独立战力层

## 1. 空间体系（炼虚阶段）

现有：

- 空间感悟；
- 空间撕裂增伤；
- 空间挪移；
- 空间禁锁；
- 虚化减伤。

商品：

- 【破界悟空礼包】
- 【虚空真髓礼包】
- 【空间神通补全礼包】
- 【炼虚道果冲刺礼包】

禁止直接把空间感悟一键堆满。

更适合：

- 补关键材料；
- 提供显著但非满值的空间感悟；
- 给一件炼虚阶段适配法宝。

---

## 2. 法则 / 领域 / 法相（合体阶段）

现有法则：

- 斩界法则；
- 焚灭法则；
- 镇界法则；
- 神禁法则。

现有进一步战力：

- 法则熟练；
- 领域；
- 法相；
- 归一度。

商品：

- 【法则顿悟礼包】
- 【领域初成礼包】
- 【法相凝真礼包】
- 【归一证道礼包】

动态逻辑：

根据当前法则与道途卖对应资源，不卖错误流派。

---

## 3. 本源 / 世界权柄 / 本命源印（大乘阶段）

现有：

- 本源感悟；
- 世界权柄；
- 世界危机；
- 本命法宝源印；
- 大乘精粹；
- 渡劫五维准备。

商品：

- 【界源大悟礼包】
- 【人界权柄礼包】
- 【本命证道礼包】
- 【大乘圆满备劫礼包】

原则：

高价大乘商品要同时强化“角色本体 + 本命法宝”，而不是只给一堆材料。

---

## 4. 渡劫体系（终局重氪区）

渡劫准备现有五维：

- 肉身；
- 神魂；
- 法则；
- 法宝；
- 阵法。

另外还有：

- 本源感悟；
- 世界权柄；
- 本命源印；
- 抗劫法宝；
- 渡劫阵法；
- 渡劫丹药；
- 渡劫技能。

商业化原则：

**玩家缺哪项，就卖哪项。**

例如：

- 肉身最低 → 【万劫不灭体礼包】
- 神魂最低 → 【太上护神礼包】
- 法则最低 → 【天道补痕礼包】
- 法宝最低 → 【本命承劫礼包】
- 阵法最低 → 【九霄阵道礼包】

雷劫失败后必须识别失败阶段，再推定向补强：

- 雷劫肉身阶段失败 → 肉身/抗雷；
- 心魔失败 → 神魂/明心；
- 法则阶段失败 → 法则护持；
- 法宝阶段失败 → 抗劫法宝/修复/本命强化；
- 蜕变阶段失败 → 仙凡蜕变资源。

绝对不要所有失败都只弹一个“再渡仙劫礼包”。

# 六、VIP8：第一核心重氪节点

名称：

**VIP8【八荒至尊】**

定位：

**第一次账号质变。**

必须让玩家领取后立刻产生：

“这已经不是原来那个号了。”

## VIP8完整奖励结构

保留：

- 1888仙玉；
- 1888灵石；
- 88高阶灵材；
- 18古修残片；
- 清除伤势；
- 当前境界修为圆满；
- 称号【八荒至尊】。

新增核心奖励：

### 【八荒至尊法宝匣】

规则：

1. 检测当前境界；
2. 检测当前道途；
3. 在“当前阶段可合理使用的顶级法宝池”中选一件最适配法宝；
4. 如果当前Build缺道途法宝，优先补Build缺件；
5. 如果已有同一法宝，则不重复发，改发同阶段另一核心法宝或高价值祭炼资源。

发放品质：

- 极品；
- 自动认主；
- 至少祭炼3层；
- 温养30；
- 默认自动装入其对应的攻伐/护身/辅助槽；
- 若玩家已有更强同槽法宝，不强制替换，只入库并提示比较。

### 法宝池示例

金丹/元婴附近：

剑：青云七星剑匣 / 青云剑心镜等；
火：赤霞焚海珠 / 赤霞离火灯等；
体：万兽镇岳印 / 万兽金身鼓等；
神：古河断禁尺 / 玄阴噬魂幡等。

化神/炼虚：

剑：太虚神剑 / 断空剑匣；
火：虚焰裂界轮 / 空炎界罩；
体：镇界玄碑 / 裂空镇岳锤；
神：太虚界镜 / 空冥定界珠。

合体：

剑：斩律天剑 / 万剑法域幡；
火：焚灭法炉 / 大日法域环；
体：镇界神柱 / 撼天归一印；
神：神禁万象镜 / 归一法珠。

大乘：

剑：开天界源剑 / 万剑界旗；
火：焚世本源炉 / 天火界轮；
体：人界定鼎柱 / 天衡镇世印；
神：天心万界镜 / 九霄承劫珠。

渡劫：

按当前最缺渡劫维度优先给：

- 九霄避雷伞；
- 太上明心灯；
- 乾坤定劫盘；
- 万劫玄衣；
- 斩劫仙剑胚；
- 或与当前道途/短板更契合的同阶灵宝。

# 九、VIP12：第二核心节点

名称：

**VIP12【太玄道君】**

定位：

**从“有一件神器”升级为“整套流派成型”。**

## 核心奖励：【大道传承·Build圆满匣】

算法：

1. 检测当前道途；
2. 检测两个同道途Build中当前得分最高的Build；
3. 枚举缺失：功法、主动技能、被动、道途法宝；
4. 优先补最影响Build成型的2~3个缺件；
5. 已有组件自动跳过；
6. 如果已经Build mastered，则转换为“高阶替代 + 法宝强化 + 熟练度强化”。

VIP12目标：

玩家领取后，至少形成一个完整、明确、能立即进入战斗的流派。

## VIP12附加奖励

- 1288仙玉；
- 1288灵石；
- 48高阶灵材；
- 10古修残片；
- 当前境界修为圆满；
- 称号【太玄道君】；
- 一批法宝祭炼/温养资源；
- 当前阶段高品质丹药。

- 本命法宝渡劫强化资源。

## 3. 阶段解锁权益

如果玩家在较低境界达到VIP15：

**不能把后期奖励全部提前塞给低境界角色。**

应记录VIP15阶段权益：

- 进入炼虚时可领一次“诸天·破界”；
- 进入合体时可领一次“诸天·法则”；
- 进入大乘时可领一次“诸天·本源”；
- 进入渡劫时可领一次“诸天·仙劫”。

这样VIP15不会因为早充而浪费，同时不会让炼气期角色拿着渡劫灵宝破坏全部成长过程。

# 十五、礼包展示原则

高价值商品必须直接展示：

# 十六、重复奖励处理

重大礼包绝不能因为玩家已经有奖励而浪费。

规则：

## 法宝重复

优先：

1. 同阶段、同道途、不同槽位的顶级法宝；
2. 同阶段Build适配法宝；
3. 仍重复则转换成：祭炼资源 + 温养资源 + 高阶材料。

## 功法重复

转换为：

- 当前Build缺失神通；
- 功法熟练度强化；
- 更高阶同路线功法。

## 技能重复

转换为：

- Build缺失被动；
- 其他核心主动；
- 熟练度/悟道资源。

# 二十、暂不做的系统

除非后续用户明确要求，不为了商业化强行新增：

- 宠物；
- 坐骑；
- 翅膀；
- 时装属性；
- 血脉；
- 神兵幻化；
- 排行榜；
- PVP；
- 公会充值榜；
- 全服首充；
- 真实支付。

理由：

现有战力层已经足够丰富。优先把已有玩法商品化，比新增一堆独立氪金坑更有实际价值，也更容易保证“买了真的强”。

# 二十一、最终商业化判断标准

每个高价商品上线前都问五个问题：

1. 玩家现在为什么会想买？
2. 它解决的是哪个明确战力缺口？
3. 买完后哪一项真实战斗公式发生改变？
4. 玩家下一场战斗能不能立刻感觉出来？
5. 如果玩家已经拥有该奖励，系统怎么避免浪费？

如果这五个问题答不清楚，这个礼包就不应该进入商城。
