# 太玄界 · 可玩版 UI 收口阶段

> 状态：CURRENT / 2026-08-29 最新产品方向

## 决策

V3.9 已经贯通凡人 → 渡劫 → 飞升 → 真仙，现阶段停止继续扩张境界与内容规模。

原计划中的 V3.10「无充值凡人到真仙总平衡」暂缓，顺序调整为：

1. 冻结 V3.9 核心玩法与 `src/game-v39.js`；
2. 先完成可玩版 UI / UX 收口，让现有系统能够被正常游玩；
3. 通过真实 GitHub Pages 公网验收；
4. 用户实际试玩后，再依据真实体验进入总平衡、数值修正和后续商业模拟阶段。

## 本阶段不做

- 不新增真仙以上境界；
- 不继续堆功法、法术、法宝、材料或敌人数量；
- 不接真实支付；
- 不为了 UI 重写 V3.9 核心逻辑；
- 不破坏 schema36 旧存档兼容。

## 第一版可玩 UI 目标

- 手机优先，桌面同时可用；
- 首页只突出当前人物、境界、关键资源、紧急事项和每日行动；
- 删除首页面向开发者的长篇版本机制说明，改成玩家导向提示；
- 将角色页过长的系统堆叠改成分组折叠，减少滚动和信息轰炸；
- 地图、天下大事、关系页保留现有完整数据接口；
- 所有 V3.9 既有 DOM ID、action data 属性和核心加载链保持兼容；
- PWA Service Worker 更换 UI 缓存版本，避免旧 UI 被缓存继续命中；
- 公网验收必须确认新 UI marker、CSS、Service Worker、V3.9 核心 SHA 和 headless 回归同时通过。

## 完成标准

只有以下条件全部成立，才可称为「第一版可玩 UI 已完成」：

- main 上 UI 文件已更新；
- gh-pages 已发布相同 UI；
- 公网 `index.html` / `style.css` / `sw.js` HTTP 200；
- 公网页面包含 `playable-v3910` 标记；
- 公网 `src/game-v39.js` SHA256 仍为 `99b3d4f0ce0b8a1cc77d9fb0706e05a856d26b3aa9b19034474d742de4962c37`；
- V2.9 → V3.9 headless regression 通过；
- V6 图标 SHA 不变；
- `PUBLIC_UI_STATUS.json = PASS` 已由真实 GitHub Pages 回读验证。
