# 0. 权威级别与执行规则

本文件是后续开发的 **Source of Truth（唯一任务基准）**。

# 1. 项目最终目标

《太玄界》不是一个只靠“点修炼→境界数字上涨”的小游戏，而是一个可长期游玩的单机修仙大世界。

玩家从凡人开始，经历：

**凡人 → 炼气 → 筑基 → 结丹 / 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 飞升 → 真仙**

其中：

- **化神绝不是直接成仙。** 化神只是人界高阶修士真正触及天地规则的起点。
- 化神之后仍有完整的人界后期篇章。
- “真仙”是当前长期项目的最终通关境界，代表真正完成仙凡蜕变并飞升仙界。
- 仙界中“真仙之后”的更高境界暂时只保留扩展口，不纳入当前强制交付范围，避免项目无限膨胀。

最终玩家从凡人走到真仙，持续面对：

- 练哪套功法；
- 学哪些法术 / 神通；
- 走哪条道途；
- 炼什么法宝；
- 哪件法宝作为本命；
- 资源先投修为、丹药、炼器还是突破；
- 去哪处地图寻找指定材料；
- 是否冒险进入高危秘境；
- 如何应对寿元与死亡；
- 突破失败是否值得再次下注；
- 进入化神以后如何理解规则、空间、法则与天劫；
- 最终如何渡过仙劫，完成飞升。

# 3. 不可违反的固定约束

## 3.1 修仙难度

- 玩家定位仍是 **普通修士**，不增加“天道酬勤”“永久倍率”“无脑无敌”等作弊核心。
- 境界越高，修炼时间、资源成本、寿元压力、失败代价必须显著提升。
- 大境界差距必须巨大，低阶不能靠单纯堆攻击轻易跨大境击杀。
- 保留真实寿元、伤势、突破失败、重伤与死亡。
- 高境界必须比低境界更难、更慢，而不是经验条简单乘 2。
- 化神以后要新增规则 / 空间 / 法则 / 天劫等机制，不能只是把 HP 与攻击继续放大。

## 3.2 模拟充值

- **绝不接真实支付。**
- 不接支付 SDK，不生成真实订单，不请求银行卡、微信、支付宝等真实支付信息。
- 所有“人民币 / 充值 / VIP”均为单机内部模拟。
- 模拟充值必须在“普通玩家不充值可从凡人完整玩到真仙”并通过总平衡后才能开发。

## 3.3 技术结构

永久固定：

- 正式运行链：`index.html -> app.js -> src/game-vXX.js`
- 浏览器直接读取完整可读源码。
- 禁止 `eval`。
- 禁止恢复历史 patch chain。
- 每个正式版本生成新的完整 `src/game-vXX.js`。
- `SAVE_KEY` 保持 `xiuxian_world_v02`。
- schema 升级必须提供旧存档迁移。
- 未来高 schema 存档必须拒绝被旧版本覆盖。
- V6 App 图标固定，不修改。
- 192 图标 SHA256：`a44e68e89072c644c9f19d2c44997ae7c9af6806facc7cc9eaf76b3e0855bdcf`
- 512 图标 SHA256：`757ff87de9b0a763d3de2afcc7e23a3c6655847fee1c9690e29bbb005ce92c7b`

## 3.4 存档兼容

- V3.9 schema36 是当前正式存档基线，后续版本必须继续提供逐级迁移。

# 4. 玩家成长体系最低深度门槛

在进入“化神后大篇章”前，至少达到以下内容密度；这是最低门槛，不是数量达标即自动完成。

| 内容 | 最低目标 |
|---|---:|
| 功法 | ≥ 28 本 |
| 法术 / 神通 / 秘术 | ≥ 60 个 |
| 装备与法宝 | ≥ 60 件 |
| 其中真正法宝 | ≥ 24 件 |
| 拥有独立主动效果的法宝 | ≥ 12 件 |
| 构筑级被动法宝 | ≥ 12 件 |
| 丹药 / 丹方 | ≥ 20 种 |
| 命名材料 | ≥ 40 种 |
| 敌人 / 妖兽模板 | ≥ 45 种 |
| 独立战斗机制敌人 | ≥ 12 种 |
| 四大道途 | 每条至少 2 套可行中高阶构筑 |

原则：

1. 不能把 60 个法术做成同一伤害公式换名字。
2. 不能把 60 件装备做成攻击 / 防御数值等差数列。
3. 每个主要境界段都必须出现新的功法、技能、法宝、材料或丹药目标。
4. 地图、宗门、秘境、敌人和经济要真实承担资源来源。

# 6. 长期境界路线

## 6.1 当前已有

- 凡人
- 炼气一层～九层
- 筑基
- 结丹 / 金丹
- 元婴
- 化神初期 / 中期 / 后期

## 6.2 新增长期路线

### 炼虚

建议细分：**炼虚初期 / 中期 / 后期 / 圆满**。

核心不是“化神加强版”，而是：

- 元神与虚空开始真正联系；
- 掌握短距离空间能力；
- 神通出现“空间穿行 / 空间封锁 / 虚化规避”等机制；
- 高阶法宝开始要求空间材料；
- 普通低阶地图逐渐无法提供修炼资源；
- 需要进入新大陆、虚空裂隙、上古禁区等高阶区域。

### 合体

建议细分：**合体初期 / 中期 / 后期 / 圆满**。

核心：

- 元神、肉身、法则感悟高度统一；
- 正式建立“法则倾向”；
- 四大道途进一步分化；
- 开始出现领域、法相、大范围战斗；
- 高阶修士战争从“个人遭遇战”提升到宗门 / 地域级事件。

### 大乘

建议细分：**大乘初期 / 中期 / 后期 / 圆满**。

核心：

- 人界修行的极限阶段；
- 修炼速度极慢；
- 单纯灵石和普通丹药基本失去意义；
- 主要追逐法则、天地本源、渡劫准备物；
- 每一个大乘修士都应是世界级人物；
- 玩家开始真正影响世界格局。

### 渡劫

**渡劫不是普通的“下一个四小境界”。**

它是一整套终局系统：

- 天劫准备度；
- 肉身强度；
- 元神强度；
- 法则完整度；
- 本命法宝；
- 渡劫阵法；
- 抗劫丹药；
- 因果 / 心魔风险；
- 雷劫阶段；
- 心魔阶段；
- 仙凡蜕变阶段。

渡劫失败可能：

- 重伤跌境；
- 本命法宝损毁；
- 寿元大损；
- 肉身毁灭但元神残留（极低概率进入特殊求生线）；
- 直接身死道消。

成功后进入飞升事件。

### 飞升 / 真仙

“真仙”是当前长期项目的最终通关境界。

飞升成功必须带来明显的系统变化：

- 脱离凡俗寿元模型，进入仙体寿元逻辑；
- 灵力体系向仙灵力 / 更高阶能量转变；
- 凡界普通材料基本失去高阶价值；
- 完成仙凡身份转换；
- 记录“第几世飞升”“总修行年数”“主要道途”“本命法宝”“重要旧缘”等通关档案；
- 解锁真仙结局与长期成就。

当前强制开发到这里结束。

**预留但不承诺当前项目：**真仙之后可在未来仙界篇继续扩展，例如更高仙道境界；不得在当前阶段提前无限扩写。
