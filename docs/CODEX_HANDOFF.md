# Codex 交接说明（refactor-v40）

## 当前唯一正式运行链

`index.html -> app.js -> src/game-v39.js`

`app.js` 还会加载现役 UI / 商店脚本。不要把 `src/game-v02.js`、`game-v13.js`、`game-v15.js` ... `game-v38.js` 当成当前核心。

## 当前任务优先级

1. 不改变玩法地整理工程结构；
2. 再把 `game-v39.js` 的纯静态数据逐块迁移到 `src/data/`；
3. 每迁移一块就做等价验证；
4. 纯数据拆完后再拆系统；
5. 最后通过独立 `assets/` + art manifest 接入图片。

## 强约束

- 不改变任何游戏数值；
- 不改变 `SAVE_KEY = xiuxian_world_v02`；
- 不改变 schema36；
- 不修改旧存档字段名；
- 不把重构与数值平衡混在同一提交；
- 不删除旧版本文件，除非当前阶段已经验证且明确归档；
- 不将图片 Base64 内嵌进核心 JS；
- 图片路径必须经由 manifest / art layer 映射；
- 一次只拆一个低耦合区域。

## 第一优先拆分对象

按顺序：`REALMS` -> `ROOTS` -> `LOCATIONS` -> 其他静态数据表。

这些迁移必须保持对象内容、键名、数组顺序完全一致。

## 完成定义

“代码移动成功”不等于完成。至少要证明：

- 页面启动；
- 旧存档加载；
- 保存 / 重载；
- 修炼；
- 地图移动；
- 战斗；
- 宗门；
- 商店；

均无新增错误，才算该阶段完成。
